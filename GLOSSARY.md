# Glossary

The words Lights and its code use for one thing each.

| Term | Definition | Do not write |
| :--- | :--- | :--- |
| Field | The dark page where the points of light drift. | canvas (in prose), board |
| Light | One of the forty points that drift, bond, age and speak. | particle, dot, star |
| Bond | A link between two Lights that stay close. | connection, edge |
| Line | A written sentence a Light speaks; the lines are the work itself. | message, quote |
| Credit | The caption entry that names a selected Light. | label, tag |
